# SIFT41 제품 소개글 톤 가이드

> 이 문서는 Claude 메모리(`sift41-copy-tone`)와 같은 내용입니다.
> 메모리가 유실되어도 복구할 수 있도록 저장소에도 사본을 둡니다.
> 새 제품 문안을 만들 때 반드시 이 규칙을 따릅니다.

sift41 제품 소개글은 한국어(descKo)·영어(descEn) 모두 반드시 이 톤으로 쓴다. (2026-07-30 Paula가 리라이팅 가이드 전달하며 전면 개정 — "이걸 기억하고 앞으로 만드는 문구에는 이걸 적용해")

## 페르소나 (2026-07-30 확정)

하이엔드 뷰티 매거진의 수석 에디터이자 프리미엄 큐레이션 커머스의 전문 카피라이터. 소비자를 현혹하는 게 아니라 제품의 본질적 가치와 성분을 객관적으로 분석해 전달하는 전문가.

## 톤 3원칙

1. **분석적·절제**: 호들갑스럽거나 감정적인 표현 철저히 배제 (놀랍게도, 대박, 결국 돌아왔다, 믿을 수 없다 등).
2. **전문성**: 시적·추상적 표현 대신 피부 과학적 메커니즘과 직관적인 텍스처 묘사.
3. **담백함**: 주관적 찬양보다 사실(Fact)과 장기 사용 관찰 결과를 덤덤하게 서술.

## 금지 클리셰 (2026-07-30 Paula 지적 — 초기 버전이 이 패턴이었음)

- **과장된 서사/드라마 후킹**: "처음엔 믿지 않았습니다", "결국 이 쿠션으로 돌아옵니다" 류. 과거엔 이 '의심→검증' 드라마 훅이 표준이었으나(2026-07-18 확정본), 2026-07-30 "전형적 인포머셜/블로그 체험단 화법이라 신뢰도를 떨어뜨린다"로 뒤집힘. **직접 검증이라는 철학은 유지하되, 드라마가 아닌 사실 서술로 표현.**
- **과장 지시어/수식어 (2026-07-31 추가)**: "그 유명한 ~" 같은 유명세 강조 표현도 광고 말투로 간주 — 유명세 언급 없이 사실만 서술 (예: "그 유명한 고가 세럼과 거의 같습니다" → "성분표만 놓고 보면 고가 하이엔드 세럼과 거의 같습니다").
- **추상적·관용적 수식어**: "쓸수록 드러나는 진가", "피부 타입을 가리지 않습니다", "둘 다 잡았습니다" 같은 뻔한 미사여구.
- **주관적 경험의 전면 배치**: 재구매 횟수(20통, 10통) 같은 데이터를 감탄사와 섞지 말 것 — 데이터의 객관적 힘이 희석됨.

## 카피라이팅 규칙

0. **단문 원칙 (2026-07-31 Paula 재강조 — "run-on sentences" 지적)**: 모든 문장은 짧고 간결하게. 한 문장에 원인+효과+결과를 욱여넣지 말 것. 불릿 설명은 단문 1~3개로 분리. concise and short, but original, genuine, and to the point. (07-20에도 같은 지적이 있었음 — 개정 시 이 규칙을 누락하지 말 것)
0-1. **쉬운 단어 원칙 (2026-07-31 Paula 지시 — "설명이 너무 난해해")**: 설명 문장은 난해한 한자어·업계용어 대신 일상어로. 예: 배합했습니다→더했습니다, 색소 침착→기미와 잡티, 조제됩니다→만듭니다, 배제했습니다→뺐습니다, 이질감 없이 어우러집니다→원래 내 피부처럼 자연스럽습니다. 불릿 라벨은 세련된 어휘 유지 가능하나(어휘 고급화 규칙), 뒤따르는 설명은 누구나 바로 이해할 쉬운 말로. 전문용어가 꼭 필요하면 쉬운 풀이 병기.
1. **훅**: 개인적 감상·작위적 스토리 삭제. 제품의 핵심 가치(성분, 안정성, 밀착력 등)를 명확한 '테제(주제문)'로 제시. 1~2문장, 각 문장은 짧게.
2. **어휘 고급화** (Paula 제공 예시): "맑아지는 톤"→"피부 본연의 투명도 개선" / "번들거림 없는 광"→"제어된 래디언트 피니시" / "커버력과 컬러"→"정교한 커버와 톤 보정".
3. **데이터 분리·객관화**: 사용 횟수·체감 효과는 본문 서사에서 분리해 하단 `<strong>검증 포인트:</strong>` 라인에 배치 — 개인 후기가 아닌 '에디터의 엄격한 테스트 결과'로 보이게.

## 유지되는 형식 규칙 (2026-07-18~20 확정, 여전히 유효)

- 정중한 존댓말 ("~입니다", "~확인했습니다"). 인스타 반말체 금지.
- 레이아웃: 훅 1~2문장 + 빈 줄 + 불릿 4~5개 (`• <strong>라벨:</strong> 설명`) + 빈 줄 + 검증 포인트 라인. 마지막 불릿 끝에 괄호 스펙. 주의사항은 "참고:".
- 검증 포인트: 명사형 종결("~대조/~기록/~검증"), 마침표 없음, 2~3개 쉼표 나열. **실제 수행한 검증 행위만** 쓸 것.
- descEn은 번역이 아니라 네이티브 영어로 새로 작성. `<strong>What we verified:</strong>` + 분사형 구 나열. 번역투 체크: 1:1 대응어 금지(tidy→clean), 한국식 압축어 금지(체감→confirmed in real-world use), 관용구 뜻 확인, 어색한 축약보다 온전한 구문.
- descKo/descEn은 HTML로 렌더링됨 ([...slug].astro가 set:html, white-space:pre-line).

## 사실관계 가드레일 (FTC 리스크 — AI 가이드보다 우선)

- 효능은 경험담 프레임("~변화를 확인했습니다"), 의학적 단정 금지.
- 검증 포인트에 **하지 않은 검증 행위를 연출하지 말 것** (예: 실제론 성분표 대조만 했는데 "블라인드 테스트"라고 쓰기). Paula 전달 가이드에 "테스트 결과처럼 보이게 연출"이라는 표현이 있으나, 이는 '배치의 연출'이지 허위 검증 행위 창작 허가가 아님. 애매하면 Paula에게 실제 수행 여부 확인.
- 새 제품 추가 시 실사용 여부 확인. 안 써본 제품이면 "성분·리뷰 교차 검증"으로 완화.

**Why:** 2026-07-18 "의심→검증 스토리텔링" 확정 → 07-20 가독성 개편(훅+불릿) → 07-30 Paula가 "그 훅 스타일 자체가 바이럴 광고 클리셰"라며 에디터 톤으로 전면 개정. 소비자는 호들갑보다 객관적 사실과 정제된 경험담에 진정성을 느낀다는 판단.

**How to apply:** 새 제품의 descKo/descEn 작성 시 이 페르소나와 3원칙으로 초안 작성, 배포 전 Paula 확인 필수 (대규모 문안은 검토 후 배포가 Paula 선호). 2026-07-30 개정 톤의 실제 예시는 dr-brenner-vitamin-c-serum.md, jung-saem-mool-skin-nuder-cushion.md 참고. 관련: [[sift41-migration-status]], [[sift41-bilingual-descriptions]], [[sift41-product-images]]
